# candidates_v3 — 第1段階（生成前の準備）

正式素材ではない。ゲーム設定には接続しない。draft_v1・finish_v2・ゲームコードは変更していない。

## 方針
- 保護マスク＝**原画1672×941の矩形全体**（アルファ0/1の穴・半透明縁を含む全RGBAバイト）。意味的な建物マスクではない。生成前に宣言済み（`masks/`、ハッシュは `prep_manifest.json`）。
- 原画の縮尺・座標系・縦941の位置合わせは維持。新しい画素は原画矩形の**外側**にだけ置く。
- L1/L2: 原画の右に接続用の帯を1本追加（L1 320px、L2 384px）。原画のオフセットは(0,0)のまま。タイル周期は1992 / 2056。
- L3: 外枠で切れた岩を閉じるため左96px・右128pxの余白。原画オフセット(96,0)。下端は地面より下で隠れるため余白なし。
  L3の追加画素は、後で src 矩形を変更しない限りゲームに出ない（本作業では設定を変更しない）。
  `ruin_right` の左辺 x=1330 が草を切る問題は原画内部なので、全矩形保護の下では画素で直せない（矩形の選び方の問題）。
- 新規画素はコーディネーターの image_gen のみが作る。本スクリプトはソース画素の無加工コピーと透明な空き領域の用意だけを行う。

## 生成後の組み立て（第2段階）
生成画像をキャンバス寸法へ合わせる（縦横比が同じ場合のみ。リサンプリングは生成画像に対してのみ）→
空き領域の画素だけを候補キャンバスへ配置 → 原画矩形を**生のバイトコピー**で復元（アルファ合成しない）→
保護領域の全RGBA一致・マスク不変を検証。文脈部分のずれは計測して報告する（ずれを隠す加工はしない）。

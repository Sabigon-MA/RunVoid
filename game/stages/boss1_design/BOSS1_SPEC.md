## B. 攻撃パターンとタイミング

### 共通の規則

- **HP:** 3。自傷1回につき 1 ダメージ。HP 3 は単発、HP 2 は三連、HP 1 は移動射撃。
- **攻撃の周期:** テレポートのクールダウン（2.0 秒）より長くする。どの段階でも「予告開始から次の予告開始まで」を 3.3 秒以上にする。
- **間合い:** 予告を始める時点で主人公との距離が 240px 未満なら、ボスは離れる方向へ最大 1.0 秒歩いてから予告する（160px/s）。壁際で離れられない場合は、予告を 0.3 秒延ばす。
  - 理由: 近い距離で撃った弾は、交換の瞬間にボスと重なってすり抜ける（C章）。
- **自傷を受けたとき:** 1.4 秒ひるむ（攻撃を中断）。その間に、ボスが撃った飛行中の弾をすべて消す（光の粒で消える演出）。ひるみが終わったら次の段階へ移る。
- **当たらない交換をされたとき:** 0.5 秒かけて主人公の方へ向き直り、今の段階の予告からやり直す（連続交換でハメられないように）。
- **足場の上へ交換されたとき:** 0.4 秒後に一方通行の足場から床へ降りる（足場の上では移動射撃をしない）。
- **ボスへの直接攻撃:** 主人公には攻撃手段がないので、ダメージ源は自分の弾だけ（既存仕様のまま）。

## C. ボスへのダメージと判定

### 自傷の条件（既存。試作で確認）

1. 弾の `self_harm` が有効（ボスの設定 `projectile_self_harm`。既定で有効）。
2. **ボスが交換された瞬間に、その弾が飛行中**だった → `self_harm_armed` が有効になる。
3. その後、弾がボスの被弾判定（64×96）に重なると、`projectile_self_damage`（今回は 1）のダメージ。弾は消える。
   死因は「攻撃」として扱われ、クリア条件を満たす（試作で `death_cause=attack` を確認）。
4. 交換の後に撃った弾は自傷有効にならない。

## D. チェックポイントの拡張

### データ

```json
"checkpoints": [
  {"id": "CP1", "x": 1560, "y": 382, "wall_gap": 800},
  {"id": "CP2", "x": 3420, "y": 382, "wall_gap": 800, "label": "ボス前"}
]
```

- **互換性:** 従来の `"checkpoint": {...}`（1つ）も読めるようにする（1要素の一覧として扱う）。両方ある場合はエラー。x の昇順であること、重複がないことを検証する。
- **`StageData`:**
  - `checkpoints: tuple[CheckpointDef, ...]` を持つ。
  - `checkpoint` は先頭を返すプロパティとして残す（既存コード・テストの互換）。
  - `start(index: int | None)` で出現位置と壁を返す。

### 動作

| 項目 | 仕様 |
| --- | --- |
| 有効になる条件 | 既存と同じ。「そのプレイで x を越えてから死ぬ」。越えたチェックポイントのうち最も先のものが有効になる |
| Game の状態 | `checkpoint_ready: bool` を `checkpoint_index: int \| None` に置き換える。死亡時は `max(現在, world.passed_index)` |
| World | `World(stage, checkpoint_index=None)`。`from_checkpoint=True` は「最初のチェックポイント」として互換を残す。`passed_index` と、目印ごとの起動状態を持つ |
| ボス戦での死亡 | CP2 を越えた後なので、リトライは CP2 から。ボスは HP 3・初期位置から（敵はすべて初期状態に戻す。既存の方針どおり） |
| 死亡画面 | 「チェックポイントから」の文言を、`label` があれば「ボス前から」にする |
| 解除 | 既存と同じ（タイトルへ戻る／最初から／クリア後のもう一度） |
| 目印 | CP2 にも同じ石碑を置く（`TerrainRenderer` が一覧を描く） |

**CP2 からの再開の確認（設計値）:**
- 壁の前面は 2,620（主人公の 800px 後ろ）。
- 主人公は 0.24 秒で戦闘開始位置（3,500）に着き、そこで壁が止まる。
- E04（3,150）は検知距離（250px）の外です。

## E. 撃破後と脱出

| 時刻（撃破から） | 出来事 |
| --- | --- |
| 0 | 最後の自傷。ヒットストップ 4 フレーム（既存）。ボスの弾をすべて消す。テレポートは引き続き使える（脱出区間の敵用） |
| 0〜1.6 秒 | 撃破の演出: ボスが膝をつき、結晶が割れて青紫の光の粒が散る。壁は止まったまま。主人公は動ける |
| 1.6 秒 | 出口の障壁が崩れる（0.5 秒）。入口の障壁も消える。カメラの固定を解き、通常の追従に戻す（なめらかに） |
| 1.6 秒 | **追跡壁が再開する。** 再開位置は「止まっていた位置」と「主人公の左端から 640px 後ろ」のうち、先にある方 |
| 1.6 秒〜 | 脱出区間（4,440〜5,840）。穴が2つ（80px）、敵（任意で交換）E05 x=4,620、E06 x=5,100 |
| ゴール x=5,760 | **ボスを倒している**かつ主人公の右端がゴールに着いたらクリア |

- **クリア条件の変更:** 「必須ボスを全員攻撃で倒した」**かつ**「ゴールに着いた」。

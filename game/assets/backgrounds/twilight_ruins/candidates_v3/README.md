## 手順
1. 第1段階（`prep_v3.py`）：生成前に、保護マスク＝原画1672×941の矩形全体を宣言（ハッシュを記録）。原画の縮尺・座標・縦941の位置合わせは維持し、外側にだけ余白を追加。
2. コーディネーターが内蔵image_genで4ジョブを生成（`imagegen_raw/`、実際のプロンプトは `*_actual_prompt.txt`）。
   出力はL1・L2・L3右が1536×1024、L3左が1535×1024。マスクを直接指定する仕組みがなく、マスクは参照画像として渡しただけ。そのため文脈部分も描き直されている。
3. 第2段階（`assemble_v3.py`）：生成画像だけを入力キャンバス寸法へ一様に縮小（乗算済みアルファ、LANCZOS）。
   空き領域に隣接する文脈帯96pxで、整数シフト±16pxの位置合わせを計測し、両側の合計誤差が最小のシフトを適用。空き領域の画素だけを候補へ配置した。
   続いて原画の矩形を**生のバイトコピー**で復元（アルファ合成なし）し、PNGへ保存・再読込したうえで全バイトの一致を確認。
   比較用に、シフトなしの別案 `*_candidate_unshifted_alt.png` も保存した。
4. 確認画像（`qa_v3.py` → `qa_v3/`）。縮尺はゲームと同じ960/1672・540/941で、広い候補を960幅へ縮めていない。

### L1（遠景の廃城）
- 内側境界x=1672：生成された丘の稜線・霞の明るさが原画とつながらず、縦の切れ目が見える（`qa_v3/L1_*_join_inner_*`）。

  生成側は霧の先端を丘として描き直していた。右側文脈の誤差は114で、シフトでは解消できない。
### L2（中景の侵食都市）
- 内側境界：原画の低い地形の隣で、生成されたアーチの肋骨の足元と瓦礫が垂直に始まる。地面の下端にも段差がある。

### L3（近景）
- 右の余白（x1768〜1895）：積石の右端が自然に閉じている。等倍・3倍、暗色・シアンの背景で、縁取りや画風の変化は見られない。**唯一使える候補。**
- 左の余白（x0〜95）：原画x=0で切れている大岩の続きが、形の違う低い岩として描かれ（上端が目測で約40pxずれる）、縦の線が見える。
- 新しい外側の端にも、地面の瓦礫が細く残っている（左は行899〜940、右は行915〜940）。地面より下に隠れる想定だが、ゲーム画面では未確認。
- 余白の画素は、src矩形を変更するまでゲームに表示されない（設定は変更していない）。
  `ruin_right` の左辺x=1330で草が切れている問題は原画の内側にあるため、矩形全体を保護している限り画素では直せない。

## 原因の分析
- 内蔵image_genには、マスクを強制する仕組みも出力寸法の指定もない。そのため文脈を描き直したうえで空き領域を描いており、空き領域の端が実際の原画と一致しない。
  原画を復元すると、その不一致がそのまま縦の切れ目になる。保護を全矩形にした結果ではなく、生成方式の限界。
- 切れ目を目立たなくするためのぼかし・混合・複製・塗り足しは、指示どおり行っていない。

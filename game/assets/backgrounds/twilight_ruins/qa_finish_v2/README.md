  縦の切れ目や建物の二重化はありません（`finish_v2_03_mid_invasion_join3x_*.png`、`bgonly_after_cam1200.png` の x≈480）。
  カメラ 2399→2400（L2 の周期境界）で背景の飛びはありません（平均差 2.34。変更前は 2.55）。
  ただし構図が変わりました（これが不採用の理由）。異星アーチは画面上端まで伸びる肋骨状から、閉じたアーチに変わっています。
  地面の下端も原画より約 30px（960×540 換算）下がり、空が覗く隙間は狭くなりました。中央の橋や塔は描き直されていますが、配置は同じです。
- **L1（不採用）**: 大聖堂が拡大・再構成され、構図が変わりました。大聖堂の右側は垂直の崖で終わります。
  つなぎ目では丘の上端が約 21px（原寸）ずれます（`finish_v2_02_far_castle_join3x_dark.png`、`bgonly_candidate_L1L2_none_cam3200.png`）。

  （`finish_v2_04_near_debris_zoom2x_left.png` と `draft_v1_…` の比較）。物体の位置も動いているため、スプライト矩形を作り直す必要があります。

## ファイル
- `{draft_v1,finish_v2}_0{2,3}_*_2tile_{cyan,dark}.png`: 960×540 に縮小したタイルを2枚、継ぎ目処理なしで並べたもの。
  `*_join3x_*`: つなぎ目の周辺 160×200px を3倍に拡大したもの。
- `{draft_v1,finish_v2}_04_near_debris_{cyan,white,black}.png` / `*_zoom2x_{left,right}.png`: L3 を対照的な背景に置いたもの。
- `game_{before,candidate_L1L2_none,after}_cam{0,600,1200,2240}.png`: World.draw の統合画面。プレイヤーはカメラ+300、
  壁の先端はカメラ+140、画面内の最初の敵にホバー輪郭を付けています。HUD はありません。
  before は従来の設定（＝現在の有効設定）、candidate は L1 と L2 を両方 none にした試験設定、after は L2 だけ finish_v2・none にした設定です（取り消し済み、記録として保存）。
- `bgonly_*_cam*.png`: 背景だけ。cam1200 / 3600 では L2 のつなぎ目が画面中央 x=480 に来ます。cam3200 では L1（none の場合）のつなぎ目が x=480 に来ます。
- `qa_render.py`: 統合画面を作るスクリプト（引数は root、出力先、ゲーム内カメラ、背景だけのカメラ）。

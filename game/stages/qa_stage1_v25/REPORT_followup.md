### C. 仮のプレイヤーモデル（N=600、−600 と −450 で同じ乱数を使う対の比較）

- 仮定した分布（初見の実測ではない）:
  - ダッシュを使う人 50%、踏み切り位置 ±20px
  - 開始時のためらい 0〜1.0秒、ゲート1で考える 0〜4.0秒、ゲート2で考える 0〜3.0秒
  - ゲート1で誤って E02 と交換する人 15%、区間3で空中交換をする人 30%
  - 照準のずれ σ=8px、外れたら0.3秒後に押し直す
- 考える時間の分布を広めに取っているので、死亡率の絶対値はこの仮定で決まります。意味があるのは −600 と −450 の差です。

| 指標 | −600 | −450 |
| --- | --- | --- |
| クリア率（このモデル） | 45.3% | 33.8% |
| 死亡率 | 54.7% | 66.2% |
| 死亡した場所 | ゲート1で 204、ゲート2で 124（すべて壁） | ゲート1で 276、ゲート2で 121 |
| ゲート1より前での死亡 | 0 | 0 |
| クリア時間 中央値／90%点 | 11.15／11.97秒 | 10.78／11.53秒 |
| テレポートの成立率（クリック回数あたり） | 85.9%（794/924） | 83.6%（643/769） |
| 　不成立の内訳 | 外した 119、blocked 11 | 外した 106、blocked 20 |
| ゲート1で誤って E02 と交換した人のクリア率 | 29.3% | 25.0% |
| 対の比較 | −600 だけクリア 75件 | −450 だけクリア 6件 |

- **テレポートの成立率:** 不成立の大半は、モデルの照準のずれ（σ=8px）による空振りです。当たり判定（36×20px、両側に6pxの余裕）に入ったクリックで成立しなかったのは「blocked」だけでした。
  これは壁が主人公の 1〜11px 後ろまで来ていたときに起きます。交換先が壁に重なるため、既存の仕様どおり交換が断られます（どのみち直後に死亡する、遅すぎたクリック）。
- **−450 だけクリアした6件:** すべて「ゲート1で誤って E02 を押す」人でした。−450 では、押そうとした時点で E02 がもう壁に飲まれていて、誤クリック自体が起きなかったためです。
  −600 は E02 が長く画面に残るので、誤った選択肢も長く残ります（次の2章）。
- **判断:** −600 を推奨します（変更なし）。初見の人が考えられる時間が、全体で 0.5 秒長くなります。
  クリア時間が 0.4 秒ほど長いのは、考える時間を長く取れた人がクリアに含まれるためで、同じ操作ならクリア時間は同じです。

## 4. 初回の必須ゲート（ゲート1）で失敗したときの再挑戦時間（`retry_compare.txt`）

時間の内訳:
- 死亡画面: 0.6 秒は入力を受け付けない（コード）＋リトライを押すまでの反応 0.5 秒（仮定、実測していない）
- 作り直し: 4ms（実測の中央値、SDL dummy）
- ゲート1へ戻る: 出現からゲート1到着まで（ボット）

チェックポイント案は、出現位置と壁の開始位置だけを変えたステージをメモリ上で作って模擬しました（実装していません）。

### 観点ごとの比較

- **追跡壁との緊張感**
  - なし: 毎回「区間1〜3を走ってからゲート」なので、壁に追われる流れがそのまま残る。
  - A: 着いたときの壁との距離が通常（889px）に近く（841px）、考えられる時間もほぼ同じ（2.7秒 vs 2.9秒）。
  - B・C: ゲートの目の前で始まるので、ゲートと向こうの E03 が遠くから見えてくる約1.3秒の「近づく時間」がなくなる。C は壁を近くするぶん緊張は強いが、考えられる時間が 2.1秒に縮む。
- **学びやすさ**
  - なし: 1回の失敗が約11秒。区間1〜3で任意の交換を使うと、ゲートで考えられる時間が1回あたり約1.5秒増えることも、繰り返すうちに学べる。ただし、ゲートだけを試せる回数は1分に5.6回と少ない。
  - A: ゲートに挑める回数が約1.7倍になる。台座の E02 と、近づく時間は残る。区間3の空中交換の練習と、前半で時間を稼ぐ学びはやり直しに含まれない。
  - B・C: 最も速く再挑戦できるが、ゲート1の「後ろの E02 を押してしまう」誤りの学習には、E02 が出現直後から画面にある分、状況が通常と違う。

### 提案（実装は承認待ち）

**案A（区間3の穴を越えた所 x=1,560、壁との距離 800px）を、ゲート1で1回失敗した後から有効にすることを推奨します。**
- 初回は最初から走るので、壁に追われる流れと、前半で時間を稼ぐ学びを損ないません。
- 失敗後は、ゲートへの挑戦が約3.4秒で戻れるようになり、考えられる時間（2.7〜3.15秒）は通常とほぼ同じです。
- 案B・Cは、近づく時間と E02 の位置関係が変わるので、ゲートの体験が通常のプレイと別物になります。
- 未決定の点:
  - チェックポイントからやり直すときの敵の状態（初期配置に戻すか）
  - クリアタイムの扱い（チェックポイントを使ったら記録を分けるか）
  - HUD での表示
  - チェックポイントなしを高難度の選択肢として残すか

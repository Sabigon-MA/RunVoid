### 実機QA（2026-11-13・Claude）

**合格扱いにしたのは下記の実測条件のみ。100%・150%は未検証。**

- 環境: Windows 11 Pro / 物理1920×1080モニター1台 / Windows設定倍率125%（`AppliedDPI=120`）/
  Python 3.15.2 / pygame-ce 2.5.8 / SDL 2.32.10。
- ゲームはDPI非対応（`GetDpiForWindow=96`）のため、125%ではWindowsがビットマップ拡大し、画面がぼやける。
- 方法: 本ファイルの診断ウィンドウ（`manual_aim_probe.py`）を外部スクリプトから操作。
  Per-Monitor DPI対応の検証プロセスから**物理ピクセル座標**へOSカーソルを移動し、実クリック（`mouse_event`）を送信。
  `clicks.jsonl` の選択対象・交換回数で判定した。テスト側での座標の割り算ではなく、SDLの実変換を通している。

#### v2.3 表示モード追加後の実機照準（125%、最終コードで実施）

v2.3 で「Fit to Window」と高DPIオプションを追加した後、同じ方法で4構成を検証した。
上記に加え、カメラを右へ 37.25px（小数）動かした直後に**新しい表示位置**の敵を選べること、
80px 動かした後に**古い表示位置**をクリックしても交換しないことを各サイズで確認した。

| 構成 | サイズ | 結果 |
| --- | --- | --- |
| Pixel Perfect・DPI非対応（既定） | 6サイズ（上表と同じ） | 49/49 |
| Fit to Window・DPI非対応 | 6サイズ | 44/44 |
| Pixel Perfect・高DPI（`--high-dpi`、`GetDpiForWindow=120`） | 6サイズ＋1536×864・1800×1000（物理px） | 67/67 |
| Fit to Window・高DPI | 同上8サイズ | 59/59 |

- Fit の表示領域は SDL `Renderer.get_viewport()` と一致（例: 1000×700 で上下に 66〜69px の黒帯、1200×675 で全面）。
- 描画領域内では `pygame.mouse.get_pos()` もイベント座標と1px以内で一致。黒帯上では `get_pos()` は 0〜959/0〜539 に丸められる
  （イベント座標は範囲外の値のまま）。クリック判定はイベント座標を使うため、黒帯で交換は発生しない。
- Fit＋高DPI の1回目の実行で、1536×864 の検証中にウィンドウ幅がOS側で 1536→1566 に変わり3ケースが失敗した。
  同条件の再実行2回はすべて成功。原因は未特定（再現時は `state.json` の `window_size` を確認する）。
- 診断ウィンドウは `--display pixel_perfect|fit`・`--high-dpi` を受け付け、`state.json` に表示モード・整数倍設定・高DPI・
  `mouse_get_pos` を出力する。

## 起動手順

READMEの手順でpygame-ceを導入した環境から実行する。

```powershell
# リポジトリ直下：自動回帰テスト
python -B -m unittest discover -s game/tests -v

# 新しい出力先を毎回使用する
Remove-Item Env:SDL_VIDEODRIVER -ErrorAction SilentlyContinue
$aimOutput = Join-Path $env:TEMP ('runvoid-aim-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
python -B game/tests/manual_aim_probe.py --output $aimOutput
```

診断スクリプトは製品のGame・描画・入力・対象選択・交換処理を使用する。
診断用に敵の移動・飛びかかりと壁を停止し、物理時間も最初は停止する。
通常プレイ全体の合格を保証するものではない。dummyドライバーでは起動を拒否する。
覆われている場合は、手動で検証ウィンドウを前面に出す。

| キー | 診断用動作 |
| --- | --- |
| R | 初期化（位置・CD・交換回数も戻す） |
| C | カメラを右へ80pxずらす |
| Space | 通常の固定物理更新を開始／停止 |
| A / D / Shift | 物理更新中の通常移動・ダッシュ |
| Esc | 終了 |

Spaceは診断操作に使うためジャンプ入力にならない。
ジャンプを含む確認は最後に `python -B game/main.py` でも実施する。
OSカーソルを表示してゲーム内照準と比較できる。

- `state.json`：サイズ、ウィンドウDPI、内部マウス座標、カメラ、対象、CD、回数。
- `clicks.jsonl`：届いたボタンイベントの内部座標、選択対象、更新前後の状態。
- 静止中はCDも停止する。成功後はRで戻すかSpaceでCDを進める。
- スクリプトは任意の`command.json`も受け付ける。前回の終了コマンドと混ざらないよう出力先を分ける。

```powershell

    ConvertTo-Json | Set-Content -Encoding utf8 (Join-Path $aimOutput 'command.json')
Get-Content (Join-Path $aimOutput 'state.json')
```

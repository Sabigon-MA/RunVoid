## v4の方針（v3からの変更点）
1. **最終的なジオメトリはv3と同じ**（L1 1992×941、L2 2056×941、L3 1896×941、原画オフセットは(0,0)/(0,0)/(96,0)）。
   v4の保護マスク `masks/*_protect_full_source_rect_v4.png` は、v3のマスクと画素単位で一致することを確認済み。
   保護対象は、透明部分・開口部も含めた原画1672×941の矩形全体。
2. **局所キャンバス**：文脈を各側546px全高（v3）から128px、行の切り出しに縮小した。
   入力だけを生成ツールの標準サイズへ拡大する（L1は×2.667、L2は×1.6、L3は×4.267）。
   これにより、境界の画素がv3の約2.9〜4.6倍の大きさで見える。
3. **新しい画素に限定した明示的なガイド**（`prep/*_GENINPUT_guide_reference_only.png`、参照専用で候補には合成しない）。
   赤い斜線＝透明のまま、緑＝上端の輪郭、青＝下端、黄＝L2の肋骨の先端を描いてよい範囲（最後の72pxだけ）。
4. **L1の霧とL2の折れた肋骨を別ジョブにする**。L1は霧と丘だけ（遺構は禁止）。
   L2は低い瓦礫を基本とし、肋骨は最後の72pxで接線方向に短く延ばして折る。
5. **合格条件を生成前に宣言**（`prep_manifest_v4.json` の acceptance_gates_predeclared）。
   位置合わせのシフトは±3px（v3は±16px）。境界の輪郭差は4px以下、値の差は原画自身の列間差の2.5倍以下。
   禁止範囲のalphaは8以下で、目視で切れ目がないこと。1つでも満たさなければ不合格とし、ぼかし・混合では隠さない。
6. L3右は再生成しない。v3の画素をそのまま使い、出所を明記して保留候補として残す。

## 実現可能性（正直な見通し）
- **L1**：x=1672の境界には霞と丘しかないため、低い地形だけで条件を満たせる。成否は生成側の精度次第。
- **L3左**：大岩の左端を96px以内で閉じるだけなので、条件内で可能。
- **L2外周は構造的な矛盾がある**。原画x=0では肋骨と壁が行174〜654の約480pxにわたって切れている。
  継ぎ目を無段差で繋ぐには、追加部分の右端にも約480pxの構造が必要になる。
  許容範囲は「72px以内で折れた先端」だが、それでも高さ約480pxの折れた断面が残る。
  これが「新しい建造物」と見えるかは、目視で判定する。不自然な場合はL2外周を不合格とし、技術上の限界として報告する。

## 3. チェックポイントの境界条件

「越えた」は、主人公の左端が x ≥ 1,560 になったことを指します。この判定は移動の直後、死亡判定より前に行います。

| 場面 | 結果 | 確認方法 |
| --- | --- | --- |
| 通常走行で通過 | 越えたフレームで有効・目印が起動。その前のフレームは無効 | 毎フレームの位置と状態を比較 |
| ダッシュで通過（1フレームの移動量は歩きの1.5倍以上） | 同上。取りこぼしなし | 同上 |
| テレポートで飛び越え（x=1,530 → E02、x≈2,000） | 1,560 を一度も踏まずに有効 → 壁で死亡 → 「チェックポイントから」 | 実際のクリック経路 |
| 越えた**同じフレーム**で死亡 | 有効（移動の直後に判定するため） | 壁の位置をそのフレームで追いつくように設定 |
| 越える**1フレーム前**で死亡 | 無効（「リトライ／タイトルへ戻る」のまま） | 同上 |
| チェックポイントより前で死亡（開始地点で壁、最初の穴に落下） | 無効 | ボット／手動 |
| 再開直後（1フレーム目）に死亡 | 有効のまま。次も「チェックポイントから」 | Game の画面遷移 |
| ゲート1で死亡（通常開始／再開） | 有効 | ボット → Game |
| ゲート2で死亡（通常開始／再開） | 有効 | ボット → Game |
| タイトルへ戻る | 解除。次の開始は最初から、目印は未起動 | Game |
| 「最初から」 | 解除。その後チェックポイントより前で死んでも無効のまま | Game |
| クリア後に「もう一度プレイ」（チェックポイントからクリアした場合を含む） | 解除。クリア画面には「（チェックポイントから）」と表示 | ボットでの実際のクリア → Game |
| ポーズの「リトライ」 | 有効なら「リトライ（チェックポイント）」、無効なら「リトライ」（最初から） | Game |

意図しない有効化・無効化は見つかりませんでした。

## 4. 再開時の整合性（通常開始との違い）

| 項目 | チェックポイントから | 通常開始との違い |
| --- | --- | --- |
| 主人公 | x=1,560、足元 y=422（G03 の上） | 位置だけ。HP・速度・向き・ジャンプ回数・空中ダッシュ・ダッシュのクールダウンなどの属性は全て同じ |

| タイマー | 0 から（画面に「（チェックポイントから）」） | 同じ |

## 6. チェックポイントの演出

`checkpoint_marker.png`（2×2）と `checkpoint_marker_zoom.png`（3倍拡大: 未起動／起動の瞬間／起動済み）にあります。

- **形:** 上が斜めに折れた石碑（幅 15px、高さ約 45px）。2段の台座と、転がった破片があります。
  - 胸の位置に異星の装置（輪と、石に食い込む3本の爪）が埋め込まれ、回路のような紋様が下へ伸びています。
- **未起動:** 装置と紋様は暗い青紫で、ゆっくりわずかに明滅します。光は出しません（画素の検査で、淡い青紫の明るい画素は 0）。
- **起動の瞬間（0.9秒）:** 光の柱が空へ伸び、地面に輪が広がります。
- **起動済み:** 核と紋様が淡い青紫（160,150,255）に光ります。周りにやわらかい光が脈打ち、核から光の粒が昇ります。
- **チェックポイントから再開したとき:** 最初から起動済みで、起動の演出はありません。HUD に「チェックポイントから再開」を2秒表示します。
- **ゲームプレイへの影響:**
  - 当たり判定を持ちません。目印の有無で、同じ入力の主人公の軌跡が完全に一致します。
  - クリックしてもテレポートの対象になりません。
  - 主人公・敵は目印より手前に描かれます。
  - 描画で全体の乱数を使わないため、物理トレースは変わりません。
